# 本地网页工作台

工作台是现有总控的浏览器客户端，用来编辑流程、启动和查看任务、阅读成果以及处理经验待办。运行状态和控制仍走 Restate；页面不维护第二份进度，也不会自动唤起 Agent。

## 启动与连接

先按[项目 README](../README.md)安装依赖、启动并登记后端，再在本项目环境执行：

```text
ai-workflow-web
```

默认浏览器地址是 `http://127.0.0.1:28100`，仅监听本机；默认后端为 `http://127.0.0.1:28080`。`AI_WORKFLOW_HOME` 指定仓库根，`AI_WORKFLOW_URL` 指定后端；也可通过 `--root`、`--url`、`--port` 为这次启动显式配置。

本仓库不包含旧任务或经验内容。新建后端中的任务和账本为空；若看见其他记录，应先核对连接地址。关闭网页不会删除后端任务，但 Agent 节点仍需要实际可用的会话领取并回报。

## 流程库

内置流程位于 `definitions/workflows`，节点位于 `definitions/nodes`。打开模板副本后，可以增删节点、选择可复用能力、填写输入与前置依赖、校验并保存为 `definitions/custom/*.json`。内置模板不被覆盖。

编辑器通过依赖选择和自动排布展示编排，不提供拖拽连线；复杂条件、回退和其他契约字段可在完整 JSON 编辑区处理。保存时校验定义及版本冲突。编辑草稿仅保留在当前页面会话内，关闭或刷新前应保存。

修改流程定义只影响后续启动。已启动任务使用原定义快照，不能通过改文件悄悄替换在途节点的职责。

## 启动、进展与控制

选择流程，填写请求及相应输入，设置调用次数、并发和尝试上限，点击启动才创建运行。运行 ID 是稳定身份；提交结果不明时先查询同一个 ID，不改编号重新提交。

任务页可以搜索或筛选运行，查看当前节点、阻塞原因、负责人、节点历史、子流程和实际结果。失败属于未完成目标；取消表示明确停止，不等于成功。完成节点的占比不是工作量百分比，跳过与完成分别展示。

- **暂停/继续：** 暂停停止新派发，不表示在途软件作业已经结束。
- **取消：** 请求停止后仍需核对已发生及未知结果，以真实回报为准。
- **答复：** 将用户输入交回原执行，由 Agent 判断是否足够继续；答复不自动等于批准。
- **消息：** 在当前任务内保留沟通内容，不自动改写需求或启动执行。
- **修订冲突：** 控制操作使用最新修订号；冲突时刷新、核对变化后再提交，不自动覆盖。

Agent 节点已派发但没有执行者时显示待领取，不能据此判断 Agent 正在工作。后端不可达、能力缺失和未知状态应按实际信息处理。

## 成果与上下游引用

任务成果区与节点详情展示同一份交付记录，包括需求、方案、执行计划、任务清单及其他文件。成果由接受报告时的内容快照固定；原文件后来修改，不会替换已归档版本。

上游依据区区分声明依赖、实际交接及执行者回报的读取/采用。传入输入只证明交接，不证明已采用。子流程成果可追溯到原始交付节点；不同版本和局部引用按具体回执关联，不按文件名合并。

仅能打开已登记的成果，不能浏览任意本机文件。单文件归档上限为 128 MiB，文本预览上限为 2 MiB；缺失或归档失败的文件明确显示不可用，不能以后来生成的文件冒充旧版本。HTML、SVG 等文件不作为活动页面执行。

## 经验待办

经验处理流程和界面随仓库提供，经验内容由后续实际任务产生。任务交付与经验维护分别记录，前者不必等待后者完成。

条目保留来源任务、依据、负责人及结果；可以领取、释放、带证据结案，或补充新证据和复用反馈。补充已结案条目不会自动重新打开；确需重新处理时使用“重新处理”并填写依据，历史结案结果仍保留。

登记待办不等于已经提炼经验，结案也不自动代表已生成 Skill 或后来复用有效。详细执行语义见 [Agent 入口](AGENT_ENTRY.md)。

## 数据与边界

流程定义属于可移植资产；任务状态、经验条目、执行回执、日志及成果是运行数据，不应加入 Git。只复制仓库不会复制这些内容。

当前工作台只供本机可信使用，没有远程登录、多用户权限或公网部署承诺。程序和 ComfyUI 节点仍需对应执行器及真实软件环境。移植后应验证实际连接、文件访问与所需软件能力，不能把定义能加载当作业务任务已经能完成。
